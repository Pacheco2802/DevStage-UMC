# DevStage - Plataforma de conexão entre empresas e estudantes

## Contexto Academico

Projeto Final de Curso — Engenharia de Software, Universidade de Mogi das Cruzes (UMC). 

**Autor**: Pedro Henrique Prado Pacheco

## Fluxo do projeto

Empresa publica um desafio técnico - Estudante analisa, realiza e submete a solução - empresa avalia essa solução - Gera portfólio e ranking entre os estudantes.

## Stack: 
- Back-end: Django
- Front-end: Django Templates + HTMX + Alpine.js + Tailwind CSS
- Banco: PostgreSQL
- Testes: pytest
- Deploy: Railway

Em desenvolvimento - Setup Inicial e primeira entrega em andamento.
