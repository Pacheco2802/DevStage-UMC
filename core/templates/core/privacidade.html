Política de Privacidade

Última atualização: 27 de setembro de 2026 · Versão 1.0

Esta política descreve como a plataforma DevStage coleta, utiliza, armazena e protege dados pessoais dos seus usuários, em conformidade com a Lei nº 13.709/2018 (LGPD).

1. Dados coletados

Coletamos os seguintes dados diretamente informados pelo usuário no cadastro:

  • Estudantes: nome de usuário, e-mail, primeiro nome, senha (armazenada como hash PBKDF2-SHA256).
  • Empresas: nome de usuário, e-mail, senha (hash) e nome fantasia da empresa.
  • Submissões: URL do repositório, URL de deploy (opcional) e descrição da solução.
  • Auditoria: IP de origem, caminho acessado e horário das ações realizadas no sistema.

2. Base legal (art. 7º LGPD)

  • Consentimento do titular no ato do cadastro (art. 7º, I).
  • Execução de contrato quando os dados são necessários para operar a plataforma (art. 7º, V).
  • Cumprimento de obrigação legal para os registros de auditoria (art. 7º, II).

3. Finalidade do tratamento

  • Autenticar o usuário e controlar acesso a funcionalidades.
  • Permitir a submissão de soluções e a avaliação por empresas.
  • Manter trilha de auditoria para segurança e integridade da plataforma.
  • Integrar com a API do GitHub para verificar existência de repositórios informados.

4. Compartilhamento

Dados de submissão (repositório, descrição) são compartilhados com a empresa responsável pelo desafio para fins de avaliação. Não vendemos, alugamos ou cedemos dados pessoais a terceiros para fins publicitários.

5. Segurança

  • Senhas armazenadas com hash PBKDF2-SHA256 e salt aleatório por usuário.
  • Comunicação HTTPS em ambiente de produção.
  • Controle de acesso por perfil (RBAC) restringindo funcionalidades sensíveis.
  • Trilha de auditoria imutável (sem edição, apenas leitura por administradores).

6. Direitos do titular (art. 18 LGPD)

Você pode, a qualquer momento, solicitar:

  • Confirmação da existência de tratamento;
  • Acesso aos seus dados;
  • Correção de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados desnecessários;
  • Portabilidade dos dados a outro fornecedor;
  • Revogação do consentimento.

Solicitações devem ser encaminhadas ao encarregado indicado no item 8.

7. Retenção e exclusão

Dados pessoais são mantidos enquanto a conta estiver ativa. Registros de auditoria são preservados por período mínimo definido por obrigação legal, ainda que a conta seja excluída, com o campo de usuário anonimizado (SET NULL).

8. Encarregado (DPO)

O encarregado pela proteção de dados pode ser contatado pelo canal oficial da plataforma. Este é um projeto acadêmico e o encarregado é o próprio mantenedor do sistema.
